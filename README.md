# Krishang Sarkar Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build step is required.

## Customize

1. Edit the name, introduction, about text, projects, email, and social links in `index.html`.
2. Change colors, typography, and layout in `style.css`.
3. Replace the placeholder project cards with your real work and links.
4. Open `index.html` in a browser, or serve the folder with any static server.

For a local server, run `python3 -m http.server` from this folder and open `http://localhost:8000`.
