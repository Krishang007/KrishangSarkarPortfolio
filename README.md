# Krishang Sarkar Portfolio

Personal portfolio website for Krishang Sarkar, built with HTML, CSS, and vanilla JavaScript.

## Run Locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update your profile, experience, skills, projects, and links in `index.html`.
- Update colors and layout in `style.css`.
- Update interactions in `script.js`.
- Replace `profile.png` with your own profile image if needed.

## Deploy

This is a static website, so it can be hosted on GitHub Pages, Vercel, Netlify, or any static hosting provider.

For GitHub Pages, push the repository to GitHub and enable Pages from the repository settings. Use the `main` branch and the root folder as the deployment source.
